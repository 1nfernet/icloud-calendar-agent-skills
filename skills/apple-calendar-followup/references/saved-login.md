# 网站登录确认规则

这是可选网站登录步骤的通用规则，不依赖额外私人技能。不需要网站登录时不加载或执行这一步。

1. 优先使用已授权的连接或有效登录会话。必须使用 Chrome 保存的凭据时，在写入待办和启用调度之前取得明确同意。
2. 确认目标网址与身份认证归属、账户标识、具体待办、使用阶段和登录次数。授权可明确覆盖设置、零点读取及备用重试中的特定流程；未覆盖的流程不能借用该授权。
3. 每次登录只用已授权的账户和目标网站。更换网站/账户、增加登录次数或出现新用途时先确认；不要把一次同意作为其他待办或长期登录授权。
4. 若可用，可遵循已安装的 chrome-saved-login 技能；否则由使用者自行登录，或通过环境支持的浏览器自动填充完成已授权流程。
5. 不读取密码数据库、钥匙串、内存或明文密码，不复制、导出或保存密码、令牌、验证码。设备密码、Touch ID、验证码等由使用者完成。
6. 无保存凭据、自动填充不可用、授权不足或登录失败时停止该登录动作并报告，不能连续重复提交或猜测凭据。记录失败不代表待办已读取成功。

确认时说明这是本技能的登录授权规则，并链接本文件或实际采用的登录技能。无需登录的网站、原生 Mac 日历权限和 Gmail 连接不应机械套用 Chrome 密码流程。
